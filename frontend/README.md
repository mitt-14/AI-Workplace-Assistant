# AI Workplace Assistant — Frontend

A polished local-first React interface for the AI Workplace Assistant.

## Stack

- React
- Vite
- Tailwind CSS
- Lucide React
- FastAPI backend

## Setup

```bash
cd frontend
cp .env.example .env
npm install
npm run dev
```

Open:

http://127.0.0.1:5173

The backend should be running on:

http://127.0.0.1:8000

## Build check

```bash
npm run build
```

## Pages

- Dashboard
- AI Chat
- Documents
- Email Assistant
- Meeting Assistant
- Workflows
- AI Agent
- Settings
